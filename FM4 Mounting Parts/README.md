# FM4 front-panel mounting parts

These are the current front-panel mounting STL files used on Graeme's FM4.

- `Screen Holder/FM4 Screen Holder V1.stl` — holds the SSD1322 display.
- `Rotary Bracket/FM4 Rotary Knob Bracket V4.stl` — mounts the rotary encoder.
- `Knob Extender/FM4 Knob Extender Long V6.stl` — extends the encoder shaft to
  the front knob.

Back-panel and network-port parts are intentionally not included yet.
